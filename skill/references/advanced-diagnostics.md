# 进阶诊断

virtual-product-positioning 的进阶模块。解决的问题是：**已经有经营事实之后，识别真正形成的能力、资产、难替代性，并清理业务结构**。

## 证据纪律继承（先读，进阶模块没有更高的事实权限）

本模块沿用主 SKILL.md 的全部证据规则：Evidence Audit（每个结论回溯来源）、证据污染防线（推断不得在后续轮次升级为事实，引用数据保留原始语义、不得经模型概括后当作新事实来源）、信号不跨级（内容/需求/商业各证各的命题）。**进阶诊断不是"更高级"的诊断，不因模块进阶而放宽事实标准。**

风险过滤（版权/AI幻觉/合规/交付/同质化）在进阶阶段同样必须过一遍——真实经营中这些风险更容易爆发（业务做大才发现版权问题、客户多了才发现交付撑不住），不得视为只属于基础报告的环节。

## 两层进入门槛

**基础门槛（必须满足）**：出现至少一种**真实经营行为，且该行为与当前产品方向存在直接因果关联**——下单 / 询价 / 主动咨询交付 / 真实客户使用 / 复购 / 转介绍。泛流量不算：一个人发了20篇内容有点赞收藏，还不触发进阶诊断——本技能的证据体系自己规定内容行为 ≠ 商业验证。**持续内容数据只能作为辅助证据，不能单独触发商业进阶。**

**触发情形（满足基础门槛后，以下现象决定诊断重点，本身不独立证明数据充分）**：复购 / 续费 / 转介绍 / 持续内容数据 / 同时经营多条业务线 / 线性收入与可复制收入发生冲突。

区分这两层的意义："我同时做三个项目"是复杂度信号不是经营证据——零交易零客户的多业务线不进本模块。反过来说：**只有持续内容数据而没有交易或真实客户行为的，仍可进入本模块（内容经营是真实行为），但诊断只能停留在内容资产与需求线索层，不得用流量数据确认任何商业能力命题**——内容数据证明传播与兴趣，不证明商业能力签名。

## 分诊规则（先过这个，再决定用不用六问）

对照六问做一次预检：**六问中若有三问以上无法挂到任何具体数据或事件，说明经营证据密度不足以支撑进阶诊断**。此时不硬撑六问——输出"当前能确认的经营事实 + 数据积累建议（继续七天验证循环，攒什么数据、攒到什么程度回来）"，退回基础流程。一个只成交过一两次的用户，被套上"多产品线积累关系"的框架，只会逼诊断者编内容凑答案。

## 输出开头：经营事实摘要（先于一切诊断语言）

诊断结论之前，先列一段**经营事实摘要**，分两栏：

- **已发生**：哪些产品卖出过、哪些人重复购买、哪些内容持续获得需求、哪些交付反复出现——只用用户给的原始数据，不加工。
- **未知**：哪些能力还只是推断、哪些资产尚未验证、哪些数据缺失。

诊断必须建立在这份摘要之上，不得让诊断语言掩盖原始数据的真实密度。

## 诊断六问（每问附证据边界；结论带失效条件）

逐一回答，每个结论挂到具体数据或具体事件，答不出的承认答不出：

1. **能力签名是什么？** 被市场反复确认的优势组合。**必须来自重复出现的经营行为模式**（反复出现的任务 + 反复出现的结果 + 反复被购买/请求的能力组合），不从职业标签、自我评价或单次成功案例归纳——"擅长结构化沟通洞察"不是签名，"连续多个客户都购买你对复杂资料的整理+判断+落地模板，而不是购买单纯信息整理"才是。失效条件：客户群构成发生实质变化（复购的是另一批人）时，签名需重新验证。
2. **哪些资产被低估？** 已在产生价值但没被当成产品资产的东西。**资产成立条件：只有已被重复使用、产生过结果、降低过交付成本、促进过成交或获客，或具备明确复用价值的东西才叫资产；单纯存量内容或文件先记为材料，不自动资产化**（"写过100篇笔记"≠"有100篇资产"）。失效条件：材料从未被第二次使用时，降回材料清单。
3. **已形成的难替代性在哪里？** 用"难替代性"而非"竞争壁垒"——早期一人公司很少有真正的壁垒，但可能已有：特定场景经验、独有案例库、用户关系、工作流、判断标准、高密度结构化知识。**不得把"有一定差异化"自动表述为"形成竞争壁垒"；只有存在明确的复制成本、替代成本或长期积累机制，才可称壁垒。**答不出就承认还没有——这本身是重要诊断结论。失效条件：出现"客户流失后可被同类服务无缝替代"的具体事实时，难替代性结论作废。
4. **AI 会替代哪部分、强化哪部分？** 分开两列：正在失去稀缺性的具体工作单元 vs 因 AI 而变得更有价值的具体工作单元。**必须落到具体工作环节**（信息检索→商品化；知识筛选→仍需判断；经验案例组织→被放大；最终责任判断→不可自动替换），禁止"AI 提高效率""AI 赋能""AI 越来越强"式泛化表述——那是趋势作文不是诊断。调整方向：把人力从第一列挪到第二列。
5. **产品之间如何形成积累关系？** 双通道检查：①内容/交付物复用——一个产品的输出能否成为下一个产品的输入、素材或获客入口；②**验证关系——一个产品产生的用户行为、问题记录、使用数据、购买理由，能否成为另一个产品的真实证据**（低价工具收集高频使用场景→发现反复卡住的环节→形成高级产品——是"产品→数据/问题→新产品"，不是"产品A内容改改变产品B"）。无积累关系的产品线如实写"没有形成积累关系"。
6. **什么东西应该停止做？** 吸引注意力但不沉淀资产、不产生付费信号的事。**停止项必须能指出其成本与缺乏结果的具体证据，不得仅因"看起来低价值"就要求停止；同时承认一种情况：某件事当前不产生付费，但可能是必要的获客基础设施——基础设施不是停止项，是成本项，如实标注即可。**没有足够证据停止某项目时，不建议停止。

**"线性收入 vs 可复制收入冲突"（触发情形之一）的处理位置**：它不单设一问，由第 4/5/6 问组合回答——AI 重构决定哪些线性环节可挪（问4）、积累关系决定线性服务能否沉淀为可复制资产（问5）、停止清单决定哪些线性投入该收（问6）；其最常见的早期形态是优势反噬检查中的"太能扛服务"（收入涨但时间没了）。

## 优势反噬检查（只处理经营事实，不处理预测）

优势失控的形态：太擅长定制→产品无法标准化 / 太擅长写作→交付越来越重 / 太懂用户→SKU 爆炸 / 太能扛服务→收入涨时间没了。**以上为常见模式，需针对该用户的具体资产逐项检查，不局限于此四类。**

两条纪律：

- **判断门槛**：只有优势已被经营结果证明有效、且其边际成本实际开始上升时，才进入反噬判断。"你很擅长定制所以以后会被客服拖死"是预测；"最近客户每次都要求特殊版本，同一产品出现大量不同交付路径"是经营事实。本模块处理后者，不处理前者。
- 每个优势问一句：**这个优势在当前规模下，正在省钱还是在制造工作量？**

失控的优势不是丢弃，是加装边界（如：定制服务单独定价、只在固定周期开放）。

## 允许没有答案（明确输出约束）

本模块的价值不是每个问题都有答案，而是**经营一段时间后，终于能知道哪些东西已被事实证明、哪些仍然只是叙事**。所以：没有壁垒→写没有壁垒；没发现被低估资产→写目前没有发现；AI 影响不确定→写无法判断；产品间没有积累→写没有形成积累关系；证据不足以停某项→写不建议停止。这些"没有"是诚实结论，不是诊断失败。

## 回退出口（与主状态机的衔接）

若诊断结论**动摇了原定位的人群/场景假设**（而不仅是运营层面的取舍）——例如发现客户群构成与定位假设不符、付费场景已迁移、某条产品线的存在依据被证伪——应回退到 Positioning 状态重新审视定位假设、重走定位收敛，而不是仅在本模块内部生成三张清单。运营问题在模块内消化，定位问题回主流程。

## 输出形式

**经营事实摘要（已发生/未知）** → 一段诊断结论 + 三张清单（继续什么 / 停止什么 / 把什么资产化），每个结论挂证据（原始数据或事件，保留原始语义）。

结尾复用主报告的**完成状态三选一**：`已完成——证据充分` / `已完成，带开放问题——以下信息仍缺` / `数据密度不足——退回验证循环积累数据`。不评分、不预测。
